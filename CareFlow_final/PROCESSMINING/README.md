# Process Mining

This module is responsible for analyzing the hospital event log using PM4Py.

## Objective

- Set up the PM4Py environment.
- Validate the hospital event log.
- Prepare the event log for process mining.
- Generate process models and process visualizations in later stages.

## Day 1

- Installed PM4Py and required Python libraries.
- Created PM4Py environment validation script.
- Verified the hospital event log file.
- Checked dataset rows, columns, and available fields.
