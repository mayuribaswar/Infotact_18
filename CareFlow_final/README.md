# CareFlow

Clinical Pathway Process Mining

## Objective

Analyze hospital event logs using Process Mining to identify operational bottlenecks and improve patient flow.

## Dataset

Hospital Event Logs

Columns:
- Case_ID
- Patient_ID
- Activity
- Department
- Timestamp
- Doctor_ID
- Nurse_ID
- Severity
- Waiting_Time_Minutes
- Status

## Tech Stack

- Python
- BigQuery
- dbt
- PM4Py
- Power BI
